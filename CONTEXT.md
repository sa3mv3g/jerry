# Ubiquitous Language

* **SEGGER RTT**: Real Time Transfer. A technology by SEGGER for bidirectional communication between a microcontroller and a host debugger. It uses the debugger's memory access to read and write data extremely fast without interrupting the application.
* **Up-buffer**: In the context of RTT, a ring buffer used by the microcontroller to send data *up* to the host debugger. 
* **Down-buffer**: In the context of RTT, a ring buffer used by the host debugger to send data *down* to the microcontroller.
* **AC DAC Channel**: A hardware output that uses a high-frequency PWM carrier and an external RC low-pass filter to generate an analog AC waveform (e.g., a 50Hz sine wave).
* **Amplitude**: The peak output level of an AC DAC Channel, previously misnamed "duty cycle". It scales the underlying PWM compare values to shape the amplitude of the output wave.
* **Phase**: The phase offset (in degrees, 0-360) of the synthesized AC waveform. Modbus registers expose this independently for each AC DAC Channel, allowing for precise multi-phase generation (e.g., 3-phase power or split-phase output).
* **Output Frequency**: The frequency of the synthesized analog waveform (e.g., 50Hz) generated by an AC DAC Channel. This is distinct from the high-frequency PWM carrier used to synthesize the wave. Fixed to 50Hz system-wide.
