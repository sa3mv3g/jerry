# Ubiquitous Language

* **SEGGER RTT**: Real Time Transfer. A technology by SEGGER for bidirectional communication between a microcontroller and a host debugger. It uses the debugger's memory access to read and write data extremely fast without interrupting the application.
* **Up-buffer**: In the context of RTT, a ring buffer used by the microcontroller to send data *up* to the host debugger. 
* **Down-buffer**: In the context of RTT, a ring buffer used by the host debugger to send data *down* to the microcontroller.
